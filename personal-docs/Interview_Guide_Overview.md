## How each page is structured

Every question bank follows the same study-friendly layout:

- **Study checklist** — "can you explain X without notes?" recall prompts
- **60-second talking points** — crisp framings for fast recall
- **Simple, then the nuance** — a plain-English take plus the deep version
- **Tabbed code / worked scenarios** — reason through real problems
- **Collapsible Q&A** — click to reveal model answers
- **Rapid-fire** table + **pitfalls** + **self-quiz**
- **Cross-links** — the matching deep-dive topic pages

!!! note "Prep tips"
    - **Talk out loud.** Reading isn't rehearsing.
    - **Time yourself** — aim for ~2 minutes per answer.
    - **Build the story bank first** if you have a behavioral round coming.
    - **Re-run the self-quizzes** the day before; they're your gap detector.
