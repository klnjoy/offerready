# Interview prep for AI / GenAI Engineers

AI engineer loops rarely stop at "what is RAG?". They test whether you can ship
an LLM feature that stays correct, safe, fast and affordable in production, and
whether you can defend every choice when the interviewer pushes back.

## What the interviews test

| Round | What they listen for |
|---|---|
| **LLM and RAG fundamentals** | Chunking, embeddings, retrieval quality, context limits, when *not* to use RAG |
| **System design** | An end-to-end design with evaluation, guardrails, latency and cost budgets |
| **Agents and tools** | Tool calling, MCP, planning loops, failure handling, human-in-the-loop |
| **Evaluation** | Offline eval sets, LLM-as-judge limits, regression gates before release |
| **Coding** | Python and API work: a small service, a retrieval step, parsing model output |
| **Behavioral** | A real project you owned, with a measurable result and a trade-off you made |

   [Interview Copilot](https://klnjoy.github.io/offerready-app/copilot) builds
   an answer from your resume and stories, labels where each point came from,
   and flags numbers you haven't shown it.
5. **Run a mock.** A voice or text mock interview, with follow-ups on what you actually said.
